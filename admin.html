Sign in

Paste your GitHub access token. It is kept only in this browser and never goes into the repository. Each person on the team uses their own.

How to create your token — once, about three minutes
  1. Org owner, once only: myggc org → Settings → Personal access tokens → allow access via fine-grained tokens.
  2. GitHub → your Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Resource owner: myggc. If it is not in the list, step 1 is missing.
  4. Repository access: Only select repositories → myggc.github.io.
  5. Permissions → Repository → Contents: Read and write. Nothing else.
  6. Expiration 90 days is sensible. Generate, copy, paste above.

If the org has approval turned on, an owner has to approve the token before publishing works.
