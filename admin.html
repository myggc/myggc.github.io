Sign in

Your GitHub token stays in this browser and never enters the repository.

How to create your token — once, about three minutes
  1. Org owner, once: myggc org → Settings → Personal access tokens → allow fine-grained tokens.
  2. Your Settings → Developer settings → Personal access tokens → Fine-grained → Generate new token.
  3. Resource owner myggc; repository access only myggc.github.io.
  4. Permissions → Repository → Contents: Read and write. Nothing else.
  5. Expiration 90 days. Copy it and paste above.
Signed in as → myggc/myggc.github.io
