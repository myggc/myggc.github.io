# Partner logos

- `partner-1.png` … — transparent PNG, landscape where the logo allows, about 800px
  wide; an SVG the partner publishes is better still (`partner-4.svg`).
- Dark lettering: the cards are white, so a logo made for dark backgrounds needs its
  white parts turned dark first. Startup Büro's lettering is the grey of their own
  light-background version; GITA publishes none, so its lettering is a plain dark grey.
- Each partner's name and file are listed in `about.html` (the `partners` list).
